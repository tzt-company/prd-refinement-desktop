# 澄清联合证据与冲突重审

实施前快照，2026-09-12。针对 pipeline 15 的联合证据缺失、未知关系误判、冲突缓存重放三个反例。

1. 分片仅提取事实、定义、条件、例外及固定原文引用，保存检查范围；多片统一形成新判断，不投票、不选择旧动作。
2. 汇总读取相关原文证据；超预算采用有覆盖记录的分批证据汇集，不截断；最终候选逐片检查反证。完整小范围沿用一次检查。
3. 跨批问题关系显式为 same/different/unknown。只有 different 构成排斥关系；unknown 不自动通过。冲突仅重审涉及的判断，补原文依据。
4. 缓存保存候选、已验证、已否决状态和尝试次数；全局否决使相关候选失效，持久化反馈后定向重审，最多三次，取消不提交正式项目。
5. pipeline 升为 16，旧检查点不续跑。复用原资料新建任务。平台未收敛不能生成业务澄清。

验收覆盖联合答案、例外反证、真实业务缺口、unknown 与 same、明确冲突、重试新增调用、重启保留失效状态、预算与原子提交；补真实冻结 PRD 运行与耗时记录，结构测试不代替语义验收。
