# HTML 与旧版 DOC 导入

目标：文件选择器接受 html/htm/doc/pdf，格式有独立解析路径，不能按 UTF-8 读取二进制 DOC。PDF 保留现有文本和逐页图像读取。

HTML 使用标准解析器提取正文结构，标题转为结构标记，表格按行保留单元格边界；图片转为待读取资产，外部资源及动态内容明确标记阻断。不执行脚本、不请求网络。

DOC 使用本机 Microsoft Word COM，只读打开、禁用宏，转换到导入资产目录中的 DOCX 后走既有解析；缺少 Word、损坏文件、超时返回可见错误。转换命令的输入输出使用参数传递。原 DOC 文件不修改。

验证：HTML 标题表格实体及图片/动态内容、现有 PDF/DOCX 回归、真实 Word DOC 转换；桌面文件选择器和导入失败反馈。模型分析质量不属于格式解析通过的证明。
