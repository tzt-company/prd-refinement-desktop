# Runtime 代理配置验收计划

## 症状与根因

macOS 从 Finder 启动桌面应用时不会可靠继承终端代理环境，Codex CLI 因直连超时而持续重连，最终被 60 秒连接检测终止。

## 修复

- Runtime 设置页增加可选代理地址。
- 配置只接受 `http`、`https`、`socks5`，拒绝包含用户名或密码的 URL。
- Codex CLI 与 DeepSeek Harness 子进程统一注入大小写代理环境变量。
- 连接检测使用当前表单值；新任务固化代理地址，已有任务保持原配置。
- Runtime 连接检测只用主模型发送一次最小请求，不重复验证同一执行器下的全部节点配置。

## 验证

1. 单测覆盖代理规范化、协议和认证拒绝、Codex 子进程环境。
2. 类型检查、生产构建、UI 契约与严格审计通过。
3. 打包应用保存代理并完成真实 Codex 模型连接检测。
