# 实施与验证计划

## 改动

1. 接收并校验当前审计产生的需求关系；未执行关系核查时不得标记通过。
2. 将证据修正改为并行生成候选、串行提交补丁。
3. 将用户补充指纹纳入输入身份，范围派生后重新计算交付评估。
4. 删除版本 17 不执行的旧流水线和空汇集节点，清理对应类型、配置和页面说明。
5. 为首次输入建立应用记录，并确定性应用本期范围决定。
6. 建议方案生成使用统一预算、全局并发和 Prompt 指标；单任务建立独立信号量。
7. 页面显示准确步骤、提示词估算、排队与完整耗时。

## 验证

- 单元测试覆盖关系写入、并行修正提交、输入哈希、范围派生、调整终态步骤和建议生成预算。
- `npm test`、`npm run typecheck`、`npm run build`、`npm run verify:premium`。
- 本地 `npm start` 桌面端逐页截图，检查任务流程、成本详情、调整任务和弹窗/展开态。
- 固定真实 PRD 执行一次升级后的 Runtime，记录完整耗时与 Token；若超过 20 分钟，保留节点级诊断而不强制终止。
