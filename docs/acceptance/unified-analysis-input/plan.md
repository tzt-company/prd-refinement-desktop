# 实施与验证计划

## 改动

1. 扩展资料包草稿、项目输入快照和调整请求类型，并通过 IPC 持久化。
2. 在首次任务调度前解析用户说明，将原话作为用户输入提供给候选识别与细化。
3. 重构资料准备页，提供默认展开说明框、自动保存状态和一个开始动作。
4. 结构化提交被采纳或修改的建议方案，修正后端一致性校验与调整引擎输入。
5. 更新 DESIGN.md、UX-CONTRACT.md 和用户说明。

## 验证

- 类型检查、单元测试、生产构建、项目 UI 校验、premium strict audit。
- 真实 Electron 检查初始态、已选文件、说明编辑、多文件展开、读取失败、建议选择与编辑等状态。
- 每轮结果写入 matrix.csv 和 round-N.md；全部通过后生成 report.md。
