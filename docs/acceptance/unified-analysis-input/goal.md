# 统一分析输入实施目标

## 总目标

首次分析和结果调整都以“资料 + 用户说明 + 已采纳建议”作为同一次可追溯输入。用户只需在一个输入区描述补充、调整或澄清；平台在 Agent 处理前保存完整快照，并在结果中保留依据。

## Sub goal matrix

| 子目标 | 状态 | 完成标准 |
| --- | --- | --- |
| SG1 统一数据契约 | 已完成 | 首次说明、建议最终文本、版本和指纹可持久化，重试不丢失 |
| SG2 首次分析处理 | 已完成 | 说明在功能识别前进入 Agent 上下文，整理指令不冒充业务事实 |
| SG3 准备页重构 | 已完成 | 文件、说明和一个开始动作处于同一阅读轴，索引自动执行 |
| SG4 结果调整统一 | 已完成 | 手改建议按最终文本提交，不依赖拼接原建议文字 |
| SG5 契约与验证 | 已完成 | 文档同步，单测、构建、静态审计和真实 Electron 关键状态通过 |

## 重大决策

- 采用一个选填自然语言输入区，不要求用户逐项分类。
- 文件索引仍是可靠性步骤，但由一次“开始分析”自动编排，不再是用户必须理解的独立动作。
- 首次说明既保留原文，又生成面向初始分析的用户来源单元；所有模型节点只接收与其职责相关的有效输入。
- 建议方案使用结构化最终文本提交，基础版本和原方案指纹用于并发校验。
