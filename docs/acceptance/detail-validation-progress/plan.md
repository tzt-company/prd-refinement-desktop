# 细化校验与进度显示验收计划

## 症状

- 逐功能细化输出在空字段仍携带证据占位组时，连续两次触发 `evidenceBindings.constraints` 数量校验失败。
- 七阶段进度直接展示浮点计算值，出现 `42.85714285714286%`。

## 修复

- 细化输出协议明确字段项数与证据绑定组数必须一致，空字段必须返回空绑定。
- 对没有对应字段的空占位组做确定性归一；有字段时继续严格校验证据组数量，并在错误中报告期望值和实际值。
- 百分比仅在展示层四舍五入为整数，内部进度保持原精度。

## 验证

1. 单测覆盖空占位归一、有字段时严格拒绝及七阶段百分比格式。
2. 全量测试、类型检查、构建与 UI 契约通过。
