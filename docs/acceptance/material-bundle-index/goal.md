# 资料包准备页目标

## 总目标

在原 PRD 选择流程内完成主文档、补充资料、识别索引和分析启动，并让桌面端在最低 1100px 宽度下保持清晰、可恢复和可操作。

## Sub goal matrix

| Sub goal | 状态 | 证据 |
|---|---|---|
| 原上传页直接选择主 PRD | PASS | round-3 |
| 支持文件、目录与拖放补充材料 | PASS | round-1、round-2 |
| 选中主 PRD 后建立清晰工作态层级 | PASS | round-4 |
| 只读取用户上传的文件，不判断缺件 | PASS | round-5 |
| 真实 Electron 加载新构建 | PASS | round-4 |

## 重大决策

- 未选择主 PRD 时保留居中单卡片入口；选择后切换为 1040px 左对齐工作态。
- 当前可执行步骤拥有唯一主按钮；是否需要补充资料由用户决定。

## Sub goal 进展

- Round 4：完成主 PRD 选中态的 Refactoring UI 重构；受控渲染层在 1440px 和 1100px 通过，真实桌面读取旧资料包后显示 4 个唯一缺件和 5 处引用，并加载生产脚本 `index-D5__lGAk.js`。
- Round 5：移除引用与缺件判断及处置界面；受控渲染层在 1440px 和 1100px 通过，缺失路径不会阻断已上传资料的索引与分析。
