# Round 17：联合原文证据与冲突重审

## 原因与实现

pipeline 15 存在三个已复现缺陷：分片各自 keep 时跳过联合推导；未合并即判定不同；局部缓存通过而全局冲突后仍重放旧结果。pipeline 16 改为事实提取、联合判断及原文反证复核；关系明确 same/different/unknown；缓存明确 candidate/verified/rejected，持久化三次预算和否决反馈，全部成功才提交临时项目。

额外反证发现复核也可能超预算、提取遗漏不能仅靠汇总重审解决。复核按最终请求重新装箱原文句段，给联合依据留空间；否决时重新提取受影响来源，其他证据复用。新关系模块独立承载问题对与一致性图逻辑，避免在原证据模块混入第二套状态；新测试模块用于独立验证该协议，调度恢复测试仍在原 scheduler 测试文件。
