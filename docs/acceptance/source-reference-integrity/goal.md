## 重大决策

- 取消模型自由输出 quote；模型只选择程序生成且绑定快照的证据 ID。
- 非法引用不自动退回整块，不做模糊匹配。
- 协议升级后从保存的原文件重新建账，不拼接旧检查点。
- 平台问题按责任节点修正并复核；有限预算内未解决则显示平台整理未完成，不能凭生成草稿标记成功。
- 复核必须分别判断原问题是否解决、修改是否产生回归、是否发现旁支问题；只有回归否决提交，旁支问题经确认后使用稳定身份进入对应责任队列，不能消耗原问题预算或撤销有效成果。
- 根治必须由稳定问题身份、版本化检查、原子提交和具体工作项恢复约束；不能只增加模型复核或根据最终 open=0 宣称通过。
- 20 分钟是端到端流程验收上限，重试不得重置；到时失败退出不算达标。优化必须同时减少重复工作并保留独立语义检查。
