# 运营报表定版需求

## 登录

- 状态为“启用”的用户输入账号和密码后，系统按账号和密码完全匹配进行校验。
- 校验成功后进入运营首页；校验失败时显示“账号或密码错误”。
- 状态为“锁定”的用户提交登录时，系统拒绝登录并显示“账号已锁定”。

## 报表导出

- 登录成功的用户可以选择开始日期和结束日期导出订单报表。
- 日期范围包含开始日和结束日，最长 31 个自然日；超过 31 日时禁止导出并显示“日期范围不能超过31天”。
- 导出文件格式为 CSV，列顺序固定为：订单号、创建时间、订单状态、订单金额。
- 查询结果为空时仍生成只含表头的 CSV 文件。
- 报表导出以登录成功为前置条件；未登录用户不能执行导出。

## 通用规则

- 页面展示时间和 CSV 中的创建时间统一使用 Asia/Shanghai 时区，格式为 `YYYY-MM-DD HH:mm:ss`。
